# TinyInstaller Releases

Release repository for **TinyInstaller**, an automated operating system deployment tool for VPS and dedicated servers.

TinyInstaller deploys and configures Windows and Linux environments directly from an existing Linux system, without requiring provider rescue mode, VNC, or manual OS installation.

## About This Repository

This repository contains the public release artifacts used by TinyInstaller, including:

* Bootstrap scripts
* Prebuilt TinyInstaller binaries
* Supporting files required during deployment

These artifacts are downloaded automatically by the TinyInstaller bootstrap process and are generally not intended to be used directly.

## How TinyInstaller Works

A typical deployment follows this workflow:

```text
Existing Linux Server
        │
        ▼
Run Bootstrap Script
        │
        ▼
Download TinyInstaller
        │
        ▼
Select Deployment Image
        │
        ▼
Detect & Configure Environment
        │
        ▼
Reboot into Installer
        │
        ▼
Deploy Operating System
        │
        ▼
Configure Network & Remote Access
        │
        ▼
Windows / Linux Ready
```

TinyInstaller automatically handles the deployment process, including environment detection, disk preparation, network configuration, operating system deployment, and remote access configuration.

Deployment progress can be monitored from the TinyInstaller web interface.

## Supported Deployments

TinyInstaller supports:

* Windows Server
* Windows desktop environments
* Linux distributions
* VPS and cloud instances
* Dedicated / bare-metal servers
* Custom operating system images

Custom profiles can use RAW disk images or virtual disk formats supported by QEMU. Compressed RAW images such as `.raw.zst` are recommended for efficient deployment.

## Bootstrap

Installation commands are generated by TinyInstaller using your access key and deployment configuration.

A generated command typically downloads the bootstrap script and executes it with the required setup key:

```bash
(wget <setup-url> -4O setup.sh || curl <setup-url> -Lo setup.sh) && bash setup.sh <setup-key>
```

Additional parameters can be used to pre-select an image, configure credentials, select ports, skip confirmation, or control the installation mode.

For security and compatibility, use the installation command generated by TinyInstaller rather than constructing one manually.

## Warning

TinyInstaller performs low-level disk and operating system deployment operations.

**Running an installation may overwrite the target disk and permanently destroy existing data.**

Always verify the target server and ensure that important data has been backed up before starting a deployment.
